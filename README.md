# 91

本工具用于分析 GPT 账号池截图，并保留原来的成本计算功能。

## 账号池分析

1. 打开 `91.app`。
2. 复制 `PLUS共享号池` 或 `K12共享号池` 看板截图。
3. 回到应用按 `Command+V`。
4. 应用会自动识别截图标题，保存到对应分组历史。
5. 在“趋势分析”顶部选择单个分组，查看每日 5h/7d 估算消耗、账号净减少、下一日预测、动态补号建议和风险。
6. 在“账号池分析”查看各分组实时概览及独立历史表里的账号总数、5h/7d 可调度剩余、并发可用、状态分布和趋势变化。

账号池历史按分组独立保存：PLUS 只和 PLUS 的上一次对比，K12 只和 K12 的上一次对比。账号池、余额和成本历史不限制条数，较早记录按页加载。

## 成本计算

原来的成本计算功能仍保留：

1. 输入成本，例如 `200`。
2. 复制基准截图，点击“粘贴为基准截图”。
3. 后续复制最新截图，点击“粘贴为最新截图”。
4. 查看各号余额对比、当前收益和回本进度。

## 隐私和 OCR

- OCR 使用 macOS 系统自带 Vision 框架，本地识别，不上传图片。
- 图片只用于当次 OCR，不复制、不保存图片路径。
- 应用只保留识别出来的结构化数字、分组和时间。

## 重新打包

在项目目录运行：

```bash
./build.sh
```

生成文件在：

```text
dist/91.zip
dist/91.dmg（当本机磁盘镜像工具可用时）
```

当前发布包按构建机架构生成；在 Apple 芯片 Mac 上生成的是 `arm64` 版本。

## 远程发布

- 2.2.15 起应用会在启动后自动检查 GitHub Releases 的 `latest.json`，下载并安装新版本，重启后生效。
- 从 2.2.14 或更早版本升级到 2.2.15 仍需手动安装一次；后续版本才会走自动更新。
- Release 包含 ZIP、SHA-256 校验文件、updater 签名包和清单，以及在可用时附加的 DMG。
- 没有 Apple Developer ID，首次从 GitHub 安装时需要在 macOS“隐私与安全性”中手动允许打开。
- updater 私钥默认保存在 `~/.tauri/91-updater.key`，密码默认保存在 `~/.tauri/91-updater.key.pass`；不要提交或上传私钥。

发布新版本前先更新 `RELEASE_NOTES.md`，然后运行：

```bash
./release.sh 1.0.1
```

脚本会在本机完成构建和校验，推送 `main`，然后上传资产并创建 GitHub Release。发布前必须保持工作区干净且 `gh` 登录有效。

GitHub Actions 只负责对 `main` 分支进行独立构建和签名校验。
